# Sum expression columns by group (pseudobulk for plain matrices).

Sum expression columns by group (pseudobulk for plain matrices).

## Usage

``` r
.aggregate_matrix_pseudobulk(mat, groups)
```

## Arguments

- mat:

  Gene-by-cell expression matrix.

- groups:

  Character/factor vector aligned to matrix columns.

## Value

Aggregated gene-by-group matrix.
